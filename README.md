## 🚀 Featured Project: PEM Sports

A production NFL analytics app covering 800+ players, teams, seasons, and matchups.

- **Stack:** React on Vercel · FastAPI on Render · Supabase PostgreSQL · GitHub Actions CI
- **Data:** Automated multi-season ingestion and transformation in Python/Pandas (cut manual effort by 90%+)
- **Modeling:** Normalized Postgres schemas with SQL-driven APIs
- **Analytics:** Weekly and seasonal yardage, touchdown, and game-total projections using linear and Poisson regression
